# Tunde Production Asset

This directory is the canonical home for Tunde's production artwork.

## Layer contract

The animation engine expects transparent PNG layers with these names:

- `back_hair.png`
- `legs.png`
- `shoes.png`
- `torso.png`
- `left_arm.png`
- `right_arm.png`
- `neck.png`
- `head.png`
- `ears.png`
- `front_hair.png`
- `left_eye.png`
- `right_eye.png`
- `left_brow.png`
- `right_brow.png`
- `nose.png`
- `mouth.png`

Artwork is deliberately kept separate from scene YAML and the movement engine.
This lets one Tunde design be reused across hundreds of scenes.

## Required views later

The first production pass should establish a consistent front-facing design.
Then create matching 3/4 and side views without changing Tunde's identity,
clothing language, hairstyle, or proportions.

Do not commit copyrighted characters, logos, or third-party artwork.
