# AFRITOON Character Comedy Bible

The cast is designed to create comedy through recognizable personalities, visual reactions and timing — not by making characters ugly or by relying on stereotypes.

## Tunde — the confident mistake

**Core joke:** Tunde acts like he has everything under control immediately before proving that he does not.

Visual language:
- Chest-out confidence.
- Big readable eyes.
- Highly mobile eyebrows.
- Mischievous half-smile.
- Sudden physical collapse when reality arrives.
- Repeated pocket checks when broke.
- Camera look after embarrassment.

Default comedy progression:
`confidence → certainty → discovery → panic → forced smile → camera look`

## Seyi — the human reaction button

**Core joke:** Seyi knows exactly what is about to happen and refuses to save Tunde from himself.

Visual language:
- Leaner silhouette.
- Restrained expression.
- Side-eye.
- Slow head turn.
- Tiny knowing smile.
- Long silent pauses.

Default comedy progression:
`observe → predict → watch → deadpan → camera look`

## Mama — the final boss of information

**Core joke:** Mama already knows the truth, so explanations usually make the situation worse.

Visual language:
- Strong grounded silhouette.
- Expressive eyes and brows.
- Hands-on-hips authority pose.
- Silent stare.
- Slow turn toward the guilty person.
- Warm expression that can instantly become serious.

Default comedy progression:
`enter → notice → silence → stare → one question → everybody exposed`

## Trio chemistry

Tunde creates the problem.
Seyi predicts the problem.
Mama discovers the problem before they finish explaining it.

Useful recurring rhythm:

`Tunde speaks → Seyi looks → Tunde continues → Seyi looks again → Mama enters → silence → punchline`

## Human-looking design rule

All three characters must remain clearly human-looking. Exaggeration is used for readability and comedy through proportions, facial animation and timing, not through distorted anatomy.

## Asset rule

Base artwork stays separate from animation state. Poses, expressions, mouths, camera behavior and emotional states are runtime data. This keeps each character reusable across hundreds of scenes.
